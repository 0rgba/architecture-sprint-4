### Мотивация

Добавление трейсинга позволит быстрее расследовать и решать инциденты на стыке разных сервисов и тем самым сэкономить время разработки и повысить клиентскую удовлетворённость

Какие метрики позволит улучшить:

- Время разбора инцидентов
- Удовлетворённость клиентов
- Уменьшение общего времени прохождения запроса за счёт поиска узких мест

### Предлагаемое решение

Внедрить трассировку с помощью платформы OpenTelemetry.
Добавить стандартные (запрос, спан, таймстемп, название ручки) и спефицичные (id пользователя, id заказа) данные во все межсервисные взаимодействия.
Сделать систему просмотра данных трассировки доступной только из внутренней сети только для пользователей, которым она нужна для работы (служба поддержки, дежурный разработкик)

### Компромиссы

Возможно, в MES не получится (или будет слишком дорого) внедрить трассировку, т.к софт был куплен у сторонних разработчиков. Если это так, то можно сделать схожие изменения на уровне интеграции.
