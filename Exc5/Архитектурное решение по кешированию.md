### Мотивация

Внедрение кеширования позволит снизить затраты на оборудование, уменьшить время взаимодействия пользователей с системой и тем самым сделать пользователей удовлетворённее


### Предлагаемое решение

- Реализовать кеширование Cache-Aside для моделей (проверять хэш или другое уникальное значение для моделей, чтобы не выполнять повторно самую дорогую операцию)
- Использовать клиентское кеширование для всей статики
- Использовать серверное кеширование для информации о заказах для внешних пользователей, т.к. обновляется она существенно реже, чем запрашивается. Использовать для этого паттерн Write-Through. Он подходит для этой системы лучше других, т.к.:
  - Есть небольшое количество точек, где заказ может меняться
  - Нужен актуальный статус, поэтому Cache-Aside не подходит
  - В этом кейсе нельзя выделить данные, которые будут запращиваться сильно (на порядки) чаще других, поэтому Refresh-Ahead тут не подойдёт
